## 3.5.0 (2026-07-14)
AESTHETIC UPDATE：强化连续调节、首屏毛玻璃选中态与动态环境背景，并加入完整更新日志导出。

### Added
- 更新日志版本列表加入毛玻璃滑块。
- 可将从 1.0.0 至今的完整更新日志导出为 UTF-8 TXT 文件。
- Color Blob 与 Blurred Cover 背景加入多轨、无规则、慢速环境运动。

### Changed
- 字体粗细改为真正连续且更明显的视觉变化。
- Crossfade 过渡时间改为 0.1 秒级连续调节。
- Blurred Cover 以超出视窗的连续色场移动，避免边缘割裂。

### Fixed
- 首次打开页面无需点击即可显示当前选中的毛玻璃滑块。
- 播放历史中的播放次数随中英文界面同步切换。

### Fixed
- 侧边栏滑块建立明确的左上定位基准。
- 所有毛玻璃滑块使用统一的轻量主题色阴影。
- 字体粗细改为 1 级步进、可变字体轴和细微合成描边。
- 页面首次加载及字体完成加载后主动初始化全部滑块。

### Fixed

- EQ 预设选中项恢复主题色高亮。
- 左侧导航改为滑动毛玻璃选中块。

## 3.4.1 (2026-07-14)
重点修复分段选择器毛玻璃错位，并补齐英文模式的全部界面与更新日志。

### Fixed

## 3.4.0 (2026-07-14)
LANG. & UI UPDATE：加入中英文界面、播放列表优先播放规则与高质感滑动选择器。

### Added
- 设置页新增中文与 English 切换，并保存语言偏好。
- 分段选择器新增带 38px 毛玻璃的伸展滑动指示块。

### Changed
- 手动播放列表始终优先于顺序、随机和单曲循环；播放完后恢复用户原播放模式。
- 点击下一首时，已在列表中的歌曲移动到最前面。

### Fixed
- 修复手动播放列表 hover 与拖拽时闪烁抽搐。
- 修复设置页版本卡片阴影缺失及黑白硬轮廓。

## 3.3.3 (2026-07-14)

### Added

### Changed

- 修复拖拽歌曲显示为直角白色长条的问题。
- 修复字体选项看起来相同或选择后没有明显变化的问题。

## 3.3.1 (2026-07-14)
修复播放队列语义与歌单按钮误播放，并补充排序、反馈提示和带把手的平滑拖拽。

### Added

- “下一首播放”和“从歌单移除”成功后显示毛玻璃弹出消息。
- 设置页顶部新增版本卡片，点击 HOTFIX BUILD 可直接打开 3.3.1 更新日志。

### Changed

- 队列拖拽入口移到歌曲长条最右侧的三横线把手，拖动时加入抬升、让位和落位动画。

### Fixed

- 修复手动播放列表与默认歌单位置显示混合的问题。

## 3.3.0 (2026-07-14)
加入独立播放队列，让临时点播不再打乱歌单和原有播放模式。

### Added
- 歌单中的每首歌曲新增“下一首播放”和“加入播放队列”操作。
- 播放器右侧新增真实播放队列，可查看顺序、拖拽排序、点击立即播放、移除单曲或一键清空。
- 歌曲自然结束、手动下一首和交叉淡入淡出都会优先读取播放队列。

### Changed
- 播放队列为空时，继续使用顺序、随机、单曲循环或每日推荐的原有规则。
- 从歌单删除歌曲时同步清理队列中的对应项目，避免失效条目。

## 3.2.2 (2026-07-14)
统一各主界面与侧边栏的上下边框基线，并补齐更新日志版本标签的点击光晕。

### Changed

- 提高窗口适配的内部设计高度，缩小普通 Edge 窗口时为播放器内容保留更稳定的纵向空间。

### Fixed

- 为更新日志的全部版本选择标签及当前版本标签加入点击光晕。

## 3.2.1 (2026-07-14)
恢复扩散式点击光晕，并集中修复睡眠定时、EQ、字体选择和更新日志入口的视觉问题。

### Changed
- 恢复第一版的外扩散 + 内发光点击反馈，取消边界白条。
- 光晕改用 4 阶低帧动画与更小的模糊范围，保留观感并降低 Edge 合成负担。
- 字体选择改为与睡眠定时器一致的自定义毛玻璃弹出菜单。

### Fixed
- 光晕动画结束后立即移除 glow-pulse 状态，修复点击过的按钮持续发光。
- 增加睡眠定时按钮与播放卡片底边之间的安全距离。
- EQ 预设改为整齐的四列网格，并恢复每个 EQ 按钮的点击光晕。
- 修复 Edge 原生字体选择框及下拉列表全白的问题。
- 修复侧边栏更新日志按钮上方两个角为直角的问题。

## 3.2.0 (2026-07-14)
降低 Edge 的视觉特效负担，重做窗口自适应，并加入可按版本浏览的内置更新日志。

### Added
- 侧边栏最底部新增“更新日志”，可以选择 Unreleased 或任意历史版本查看。
- 新增统一 app shell 缩放器：窗口不足设计尺寸时整套桌面布局按比例缩小。

### Changed
- 点击光晕由多层模糊阴影改为短促的粗线框反馈，减少合成与重绘。
- 降低环境光斑、封面虚化和玻璃面板的模糊半径；缩小窗口时暂停光斑漂移动画。
- 全屏时自然填充可用空间，非全屏时保持完整双栏排版并自动适配窗口边界。

### Fixed
- 修复 Edge 非 F11 状态下界面被窗口边界裁切、需要手动缩放至 90% 的问题。
- 修复左右栏在临界宽度换行造成的布局跳动。
- 固定歌曲标题和艺人信息行高，长文本使用省略号，切歌不再改变播放卡片尺寸。
- 修复首次打开、尚无本地偏好设置时 7 段 EQ 滑块没有生成的问题。

## 1.0.0 (2026-07-07)
Glass Player 的首个可用版本。

### Added
- 播放/暂停、上一首/下一首、进度拖拽、音量、静音、随机和循环。
- 文件、文件夹和拖放导入，按歌名/艺人搜索。
- 深色/浅色/自动主题、主题色、字体和字体大小设置。
- iOS 风格玻璃卡片、动态背景光斑和旋转唱片。

### Known limitations
- 刷新后必须重新导入音频文件。
- 不显示歌词。
