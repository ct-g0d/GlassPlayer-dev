- [ ] **Step 2: Implement feature extraction and bounded similarity**

Implement `featureVector(track)` with a 13-value MFCC copy, finite BPM,
confidence, stable key and coverage. Use fixed safe scales for pairwise
comparison and a robust per-layout normalization pass for PCA. Implement one
`compareTracks(left, right)` path that returns `{mfcc, tempo, genre, overall,
coverage, confidence}` with every score clamped to `[0,1]`; make identical
complete vectors return `overall: 1`.

The central comparison shape is:

```js
const mfccScore = mfccDistance <= 0 ? 1 : Math.exp(-mfccDistance / 13);
const tempoScore = bothBpm ? Math.exp(-Math.abs(left.bpm - right.bpm) / 24) : .28;
const genreScore = offlineGenreSimilarity(left, right);
const overall = clamp(mfccScore * .60 + tempoScore * .25 + genreScore * .15, 0, 1);
```

Use existing `GP.genreRelations` only when available; unknown labels receive a
bounded lexical/equality fallback. Do not copy the Neural distance formula
into this file later.

- [ ] **Step 3: Implement deterministic projection and clusters**

Implement `buildLayout(tracks, options)` in these bounded stages:

1. derive vectors and feature coverage;
2. calculate normalized means and covariance for usable vectors;
3. derive two principal directions with a fixed 12-iteration power method and
   deterministic sign selection;
4. choose `k = clamp(Math.round(Math.sqrt(trackCount / 2)), 1, 8)` and use
   stable-key seeded farthest-point centers followed by at most 12 refinement
   passes;
5. place cluster centers along two logarithmic spiral arms and place each
   point from its projected local vector plus stable identity jitter;
6. calculate concise genre/tempo labels and return finite point radii,
   opacity, color-family index, clusters, labels, coverage and a signature.

The layout must sort only internal calculations by stable key and restore the
caller-independent point order by stable key before returning. Track identity
must never be replaced by title or artist.

- [ ] **Step 2: Implement mount, resize and destroy**

four existing hooks once, obtains one 2D context, installs one resize listener,
one pointer listener set and one Escape listener, and returns a frozen
controller. `destroy()` removes every listener, cancels the pending animation
frame, clears the tooltip and releases cached Canvas layers.

The resize handler measures CSS pixels, sets backing dimensions to
`min(devicePixelRatio, 2)`, updates the viewport transform and schedules one
frame. It never rebuilds the feature layout unless the stable track signature
changed.

- [ ] **Step 3: Implement cached atmosphere and point rendering**

draw cluster labels and the selected point. Restore the Canvas composite mode
before drawing labels. Do not call a large `shadowBlur` inside the point loop.

The frame function receives `now`, computes elapsed progress for layout
interpolation, draws once, and schedules another frame only while interpolation
or an active pointer transition is still required. Reduced motion presents the
target layout immediately.

- [ ] **Step 4: Implement stable layout refresh**

`refresh()` calls `getTracks()`, passes the snapshot to `galaxy.buildLayout`,
keeps the previous point map by stable key, and animates only changed points.
For an empty library, draw the empty atmospheric state and a concise localized
instruction. For incomplete features, draw dim peripheral points and update
the coverage status without triggering analysis.

new view-transition engine. Bootstrap mounts the controller after the existing
